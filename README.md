# G&M Imports — Protótipo de e-commerce

Protótipo front-end responsivo com:
- home premium
- catálogo de body splashes
- filtros por vibe, família olfativa e intensidade
- busca
- favoritos
- carrinho lateral
- quiz de recomendação
- comparação de fragrâncias
- newsletter
- layout mobile-first

## Como visualizar
Abra `index.html` no navegador.

## Imagens reais de produtos
O protótipo usa nomes reais de produtos como referência de catálogo, mas deixa as imagens como placeholders por segurança de direitos de uso. Substitua o campo `image` em `app.js` por URLs ou arquivos que a G&M Imports tenha autorização para usar comercialmente.
